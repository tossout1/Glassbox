Analysis environment

Linux — Debian 12 ARM64

This release supports Linux analysis only.

Files run only inside the configured QEMU sandbox. Analyses are queued and run in independent VM workers. Maximum upload: 30 MiB.

Uploaded files and temporary server copies are deleted when analysis finishes. Temporary changes inside the VM are discarded when it stops. Reports stay in server memory temporarily so the page can show the results.
